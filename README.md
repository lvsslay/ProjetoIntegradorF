Sobre o Projeto: Este site tem como objetivo apresentar uma análise histórica e visual sobre o Estado Livre do Congo (1885–1908). O tema foi escolhido por sua relevância histórica e pela necessidade de expor as consequências do imperialismo europeu na África. O conteúdo aborda a apropriação do Congo como propriedade privada do Rei Leopoldo II, o ciclo econômico da borracha impulsionado pela invenção do pneu, o regime de terror e a política das Mãos Cortadas, além das denúncias internacionais (Relatório Casement) e a independência.
Tecnologias Utilizadas: HTML5 para estruturação semântica do conteúdo. CSS3 para estilização e layout responsivo, utilizando como base o template Massively (HTML5 UP) com personalização completa da paleta de cores para tons de cinza, preto e branco, visando transmitir a seriedade do tema. JavaScript para implementação de interatividade no cliente, incluindo a criação de um Quiz Histórico dinâmico com lógica de validação de respostas.
Funcionalidades: Navegação SPA (Single Page Application) com menu de rolagem suave para as seções históricas. Design responsivo adaptável a computadores, tablets e celulares. Quiz interativo com feedback visual imediato e barra de progresso.
Desafios Enfrentados: Ajuste na estrutura de pastas para a hospedagem no GitHub Pages devido à diferenciação de maiúsculas e minúsculas em servidores Linux. Correção do comportamento da imagem de fundo que era ocultada pelo template original em certas resoluções, exigindo ajustes manuais no CSS. Manipulação do DOM via JavaScript para criar o sistema de quiz sem recarregamento da página.
Créditos: Conteúdo baseado em pesquisa de fontes históricas. Design original do template Massively por HTML5 UP, licenciado sob Creative Commons.
